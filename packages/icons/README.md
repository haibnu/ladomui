# @ladom/icons

The icons of [Ladom UI](https://ui.ladom.co) as React components: Ladom names mapped to Tabler icons, plus custom icons from the Ladom UI Figma file.

```bash
npm install @ladom/icons
```

```tsx
import { IconPhone } from '@ladom/icons';

<IconPhone size={20} />; // decorative
<IconPhone title="Call" />; // with an accessible name
```

Browse them at [ui.ladom.co](https://ui.ladom.co/en/docs/foundations/icons). MIT licensed.
